## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **FPS Unlocker** | Remove the 60fps cap and enjoy Roblox at your monitor's refresh rate |
| **Custom Flags** | Fine-tune Roblox's internal flags for performance and visual improvements |
| **Multi-Instance** | Run multiple Roblox accounts simultaneously on the same Mac |
| **Native Apple Silicon** | Optimized for M-series chips for better performance and battery life |
